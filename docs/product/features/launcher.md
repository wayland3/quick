# 启动器

## 输入解析

| 输入 | 行为 |
|---|---|
| 纯文本 | 应用搜索 + 本地翻译（可选）+ 搜索兜底 |
| `>` | 列出全部内置命令 |
| `> <命令>` | 过滤并定位到该命令 |

内置命令（中英文别名等价）：

| 命令 | 别名 | 行为 |
|------|------|------|
| 锁屏 | `lock` | 立即锁定屏幕 |
| 睡眠 | `sleep` | 系统进入睡眠 |
| 设置 | `settings` | 打开设置窗口 |
| 清空剪贴板 | `clear` | 直接清空全部历史（含置顶），不弹确认 |
| 重建索引 | `rebuild` | 重新扫描应用 |
| 退出 | `quit` / `exit` | 退出 Quick |

## 划词预填

- 热键触发瞬间读取前台选中文本：
  - 读到 → 预填输入框（替换当前查询词），同时查询应用和翻译
  - 读不到 → 保持现状（启动器保留上一次查询词，见 `global.md`）
- **读取选中文本是 platform 层统一接口**，复用 convert 功能的实现
- 应用兼容性与 VS Code / 终端 / TUI 的限制见 `docs/product/features/convert.md` §9「划词兼容性」

## 结果与排序

- 按优先级分组：**应用 → 本地翻译（命中才显示）→ 搜索引擎**
- 合计 ≤10 条，与浮层一屏对齐，**一屏全部显示，无需滚动**
- 混合结果（含翻译/搜索行）不显示分组标签——行内已有图标和名称区分类型
- 各部分数量由设置控制，超出总条数限制时按优先级截断

### 应用

- 列表项显示应用图标，无图标时显示占位符号
- 匹配优先级：完全前缀 > 词首缩写（`vsc` → Visual Studio Code）> 子串 > 模糊
- 同分时按 frecency：`score = 匹配分 × (1 + ln(1+使用次数)) × 时间衰减`，衰减半衰期 14 天

### 本地翻译

- 图标：圆角徽章「译」字
- 英 → 中：显示音标 + 释义
- 中 → 英：显示拼音 + 英文释义
- 未命中时不显示此行
- 由「翻译」开关独立控制

### 搜索引擎

- 默认预置 Google 和百度
- 用户可自定义搜索引擎列表（最多 3 条）
- 每项显示品牌图标（无图标时回退为首字占位）+ 名称；图标不超出行首图标列
- 由「搜索兜底」开关独立控制
- 执行时在浏览器中打开搜索结果页

## 执行

- `Enter` 执行选中项：
  - 应用行 → 打开应用
  - 本地翻译行 → 复制释义到剪贴板
  - 搜索兜底行 → 打开浏览器（Google / 百度）
- `Ctrl+Enter` 同上但不关闭浮层
- 执行失败时保留面板并提示原因（应用已卸载 / 无权限 / 找不到关联程序）

## 翻译方向

双向翻译，自动检测语言：

| 输入类型 | 翻译方向 | 本地词典 |
|---------|---------|---------|
| 英文单词/短语 | 英 → 中 | ECDICT |
| 中文 | 中 → 英 | CC-CEDICT |

语言检测规则：
- 输入包含中文字符 → 中 → 英
- 输入不含中文字符（纯英文/拉丁字母等）→ 英 → 中
- 混合输入同样按是否含中文字符判定

## 本地词典

### 英 → 中：ECDICT

- **来源**：[skywind3000/ECDICT](https://github.com/skywind3000/ECDICT)（MIT 协议）
- **数据量**：基础版 76 万词条
- **格式**：SQLite 数据库，打包进应用
- **查询策略**：精确匹配 → 词形还原（lemma）→ 未命中

### 中 → 英：CC-CEDICT

- **来源**：[CC-CEDICT](https://cc-cedict.org/)（Creative Commons 协议）
- **数据量**：约 12.5 万条
- **格式**：SQLite 数据库，打包进应用
- **查询策略**：精确匹配简体/繁体

### 加载策略

- 懒加载：首次查询翻译时才加载词典
- 不缓存查询结果（查询开销小）

## 设置

| 设置项 | 默认值 | 说明 |
|---|---|---|
| 翻译 | 开启 | 控制是否显示本地翻译行 |
| 搜索兜底 | 开启 | 控制是否显示搜索引擎行 |
| 应用搜索条数 | 5 | 范围 3–10，与翻译/搜索共享总条数上限 |
| 搜索引擎列表 | Google、百度 | 最多 3 条，支持增删改排序 |

### 总条数约束

- 应用数 + 翻译(0/1) + 搜索数 ≤ 10
- 超出部分按优先级截断：应用 > 翻译 > 搜索
- 保持一屏不滚动体验

## 边界与错误

- 本地词典查询失败时仅跳过翻译行并记日志，不影响应用搜索与搜索兜底
- 浏览器打开失败时，显示错误提示（如默认浏览器未设置）
- 错误提示遵守全局约定：浮层内中文提示

## 明确不做（v1）

- 在线翻译 API 集成（Google Translate API / 有道 API 等）
- 翻译历史记录
- 发音播放（TTS）
- 生词本 / 收藏
- 多词典源切换
- 独立翻译热键和浮层模式

## 讨论决议记录

| 决策点 | 结论 | 备注 |
|---|---|---|
| 翻译入口 | 合并进启动器，不单独设翻译功能与热键 | 用户指定，目的是减少热键数量 |
| 词典 | 英→中 ECDICT（MIT），中→英 CC-CEDICT（CC BY-SA） | 沿用原翻译方案选型，纯本地不联网 |
| 兜底行为 | Google / 百度**搜索**（非翻译页），始终显示 | 用户指定：兜底是搜索，不限于翻译 |
| 结果条数 | 5+1+2=8，与一屏 8 行对齐，无需滚动 | 用户指定；关闭翻译后应用上限 8 |
| 浮层高度 | 400 → 480px（一屏约 8 行） | 启动器/转换统一；剪贴板动态调高不受影响 |
| 输入上限 | 不设 | 用户指定 |
| 划词 | 复用 convert 的 platform 接口，但启动器用无副作用入口 | 评审修正：禁用 Ctrl+C 回退 |
| 原翻译文档 | 已删除，结论并入本文档 | `translate.md` 不再单独存在 |
| 翻译/搜索开关 | 拆成独立开关 | 2026-11-25：用户可独立控制翻译和搜索 |
| 应用条数 | 可调 3–10，默认 5 | 2026-11-25：用户指定 |
| 搜索引擎 | 可自定义列表，最多 3 条 | 2026-11-25：用户可增删改排序 |
| 总条数约束 | 应用+翻译+搜索 ≤ 10，超出按优先级截断 | 2026-11-25：保持一屏不滚动 |
