# 启动器

## 输入解析

| 输入 | 行为 |
|---|---|
| 纯文本 | 应用搜索 |
| `>` | 列出全部内置命令 |
| `> <命令>` | 过滤并定位到该命令 |

内置命令（中英文别名等价）：

| 命令 | 别名 | 行为 |
|------|------|------|
| 锁屏 | `lock` | 立即锁定屏幕 |
| 睡眠 | `sleep` | 系统进入睡眠 |
| 设置 | `settings` | 打开设置窗口 |
| 清空剪贴板 | `clear` | 直接清空全部历史（含置顶），不弹确认 |
| 重建索引 | `rebuild` | 重新扫描应用 |
| 退出 | `quit` / `exit` | 退出 Quick |

## 结果与排序

- 最多 12 条，分组：应用 / 命令
- 列表项显示应用图标，无图标时显示占位符号
- 匹配优先级：完全前缀 > 词首缩写（`vsc` → Visual Studio Code）> 子串 > 模糊
- 同分时按 frecency：`score = 匹配分 × (1 + ln(1+使用次数)) × 时间衰减`，衰减半衰期 14 天

## 执行

- `Enter` 打开应用
- 执行失败时保留面板并提示原因（应用已卸载 / 无权限 / 找不到关联程序）
