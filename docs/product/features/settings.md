## 常规页底部说明

「常规」页最底部是「划词读取说明」区块：上方是「划词读取增强」开关（`selection_copy_fallback`，默认开），下方固定 4 条提示：

- VS Code：默认不向系统暴露编辑器选区。需要设置一次以开启无障碍模式 `Shift+Alt+F1`
- 终端里的 TUI（如 opencode）：普通拖拽会被应用接管，终端没有选区。按住 `Shift` 选择后再按快捷键
- 增强模式读取钉钉等不暴露选区的应用；不会在终端与 VS Code 等内嵌终端中触发，避免中断正在运行的命令
- 以上限制只影响划词预填，手动输入不受影响

「划词读取增强」的行为规格见 `docs/product/features/convert.md` §9。

## 关于页

- 显示实际数据目录（数据库与图片 blob 所在位置），路径由后端返回，不写死平台地址
- 点击「打开目录」用系统文件管理器打开该目录
