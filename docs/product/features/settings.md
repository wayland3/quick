# 设置项

| 分组   | 项                  | 默认                  | 可选值                        |
|--------|---------------------|-----------------------|-------------------------------|
| 常规   | 开机自启            | 关                    | 开 / 关                       |
| 常规   | 主题                | 跟随系统              | 跟随系统 / 浅色 / 深色        |
| 热键   | 启动器 / 剪贴板     | `Alt+Space` / `Alt+V` | 任意含修饰键的组合            |
| 剪贴板 | 启用记录            | 开                    | 开 / 关                       |
| 剪贴板 | 记录文本            | 开                    | 开 / 关                       |
| 剪贴板 | 记录图片 / 文件列表 | 开 / 开               | 开 / 关                       |
| 剪贴板 | TTL                 | 15 天                 | 7 / 15 / 30 / 90 / 永不       |
| 剪贴板 | 条数上限            | 10,000                | 1,000–50,000                  |
| 剪贴板 | blob 预算           | 500MB                 | 100 / 200 / 500 / 1000 / 2000 |
| 剪贴板 | 粘贴后还原原剪贴板  | 关                    | 开 / 关                       |

## 关于页

- 显示实际数据目录（数据库与图片 blob 所在位置），路径由后端返回，不写死平台地址
- 点击「打开目录」用系统文件管理器打开该目录
