# 快速转换

> 定稿日期：2026-11-24。

## 1. 概述

热键唤起的浮层转换工具：划词或手动输入，实时输出时间 / MD5 / JSON 格式化结果。定位是「选中即转、按键即得」的高频小转换，不做通用计算器。

## 2. 入口与热键

| 项 | 值 |
|---|---|
| 默认热键 | `Alt+Q`，可在设置中改绑 |
| 形态 | 第三个浮层模式 `convert`，复用现有浮层窗口，浮层行为完全继承 `global.md`（位置、失焦隐藏、Esc、切替语义） |

- 热键触发瞬间读取前台选中文本：
  - 读到 → 预填输入框，立即出结果
  - 读不到 → 空输入框，等待输入或粘贴
- **读取选中文本是 platform 层统一接口**，各平台选无副作用的实现：
  - Windows：UI Automation TextPattern（焦点控件选区）
  - Linux：X11 PRIMARY 选区
  - macOS（未来）：Accessibility API，接口预留
  - 模拟按键复制（Ctrl+C 类）有副作用（污染剪贴板、触发自身剪贴板记录、终端误中断），v1 不做
- 隐藏时清空输入（时间是易变数据，保留旧输入无意义）

## 3. 空态（无输入时）

- 显示**当前时间快照**：各时区时间（按时区列表顺序）+ 当前秒级时间戳
- 静态定格，不逐秒刷新（目的是复制，跳动干扰选择）
- 受「时间」转换器开关控制；时间关闭时空态仅显示输入提示

## 4. 转换器

### 4.1 时间

输入识别（识别成功时时间组置顶显示）：

| 输入形态 | 判定 |
|---|---|
| 10 位纯数字 | Unix 秒时间戳 |
| 13 位纯数字 | Unix 毫秒时间戳 |
| 年份（无时区） | 四位数字 `YYYY`，按 `YYYY-01-01 00:00:00` 处理 |
| 时间字符串（带时区） | ISO8601：`T` 分隔、`Z` / `+08:00` / `+0800` 后缀 |
| 时间字符串（无时区） | `YYYY-MM-DD`、`YYYY/MM/DD`、含时分秒（可含 `.毫秒`） |

输出规则：

- 时间戳输入 → 各时区时间（按时区列表顺序，标签为时区名）
- 带时区的时间输入 → 各时区时间 + 秒级时间戳 + 毫秒级时间戳
- 无时区的时间输入 → **多个时间戳**：按时区列表逐个假设输入的时区，每个输出秒级与毫秒级两个，标签注明假设（如「输入为 UTC +8」）。不做单一本机时区假设，也不展开各时区时间（N×N 组合爆炸，输入本身已是人类可读时间）
- **空态快照**：各时区时间 + 秒级时间戳 + 毫秒级时间戳

### 4.2 MD5

- 任意非空输入 → 32 位小写十六进制（UTF-8 编码）

### 4.3 JSON 格式化

- **只接受 object 或 array**：标量（数字、字符串、布尔值、null）虽然合法 JSON，但无格式化意义，跳过
- 提取：先整体解析（快路径）；失败则用多起点括号深度扫描——遍历每个 `{` / `[` 作为起点，扫描到深度归零后用 JSON 解析验证，有效即返回。这样可以处理连续括号（如 `{{`）或杂质前缀的情况
- 容错：支持常见非标准 JSON 变体，按顺序清洗：
  1. **去除多余转义**：`{\"name\": \"value\"}` → `{"name": "value"}`（从日志或 API 响应中复制的 JSON）
  2. **移除注释**：`// 单行` 和 `/* 多行 */`
  3. **单引号转双引号**：`{'name': 'value'}` → `{"name": "value"}`
  4. **无引号键加引号**：`{name: "value"}` → `{"name": "value"}`
  5. **移除尾部逗号**：`{"a": 1,}` → `{"a": 1}`
- 输出：2 空格缩进美化（不做压缩）
- 提取失败：显示灰色提示行「未检测到 JSON」（表明开关生效但无结果）

## 5. 结果列表

- 复用启动器列表组件体系（`qw-search` / `qw-list` / `qw-row`）
- 行结构：**标签（转换来源，如 `UTC +8` / `MD5` / `JSON`）+ 值**
- **JSON 优先**：成功格式化出 JSON 时，JSON 结果排在列表第一位；其余按时间 → MD5
- 键盘：`↑↓` 选择、`Enter` 复制并关闭、`Ctrl+Enter` 仅复制不关闭、`Esc` 关闭
- 鼠标：单击选中并复制到剪贴板（不关闭浮层），双击复制并关闭
- 列表行截断显示，复制的是完整值（JSON 美化后可能很大）
- 复制后自动入库剪贴板历史（与剪贴板面板行为一致）

## 5.1 布局

- **左右分栏**：左侧结果列表，右侧 JSON 详情。选中 JSON 结果时右侧显示树形详情，其余情况右侧隐藏
- **两侧互不影响**：左侧列表保持原有宽度与布局，右侧详情是独立窗口，可按住标题栏拖拽移动
- **JSON 详情失焦策略可配置**：默认失焦时自动隐藏；在「转换」设置中关闭「JSON 详情窗口失焦时自动关闭」后，主浮层或详情窗口因点击外部失焦时详情保留。切换非 JSON 结果、切换模式或主动关闭主浮层仍关闭详情；点击详情标题栏关闭按钮（×）始终主动关闭详情，不受失焦设置影响，失败时提示重试
- **JSON 树默认全部展开**，点击节点可折叠/展开
- 主浮层始终保持标准尺寸（640×480），切换 JSON 结果不移动、不缩放主浮层
- 右侧详情窗口独立按内容调整宽度和高度：可用空间足够时加宽；顶部优先与主浮层对齐，只有详情底部放不下时才向上移动，超过整个工作区时贴顶并允许滚动
- 详情正文使用 11px 等宽字体，不改变主浮层的结果文字字号
- 两侧空间都不足时详情可能与主浮层重叠，但不得为详情移动主浮层
- 折叠 JSON 节点时详情窗口尺寸保持不变

## 6. 设置（新增「转换」页签）

- 热键录制：复用 `HotkeyRecorder`
- 转换器开关列表：时间 / MD5 / JSON 格式化，右侧开关、列对齐；关闭的转换器不参与输出
- 时区列表（时间项子设置）：
  - 仅固定 UTC 偏移（`UTC +8`、`UTC +5:30` 等），不做 IANA / DST
  - 预设下拉 + 自定义偏移；可添加、删除、**拖拽排序（顺序 = 输出顺序）**
  - 至少保留一条；默认 `[UTC +8, UTC +0]`
  - 时区标签统一显示为 `UTC +8`、`UTC -5`、`UTC +0`，`UTC` 与偏移之间保留一个空格；内部设置值仍为 `+8`、`-5`、`0`
- 新增设置字段：`convert_hotkey`、`convert_time_enabled`、`convert_md5_enabled`、`convert_json_enabled`、`convert_timezones`
- 不设功能总开关（三个子开关 + 热键已足够）
- JSON 详情窗口失焦时自动关闭：默认开；关闭后失焦不隐藏详情，不影响主动关闭与结果切换

## 7. 边界与错误

- 输入长度上限 1MB，超限浮层内提示
- 各转换器独立成功/失败，互不影响
- 错误提示遵守全局约定：浮层内中文提示，不暴露内部错误

## 8. 明确不做（v1）

- JSON 压缩、MD5 变体（大写 / 16 位）
- IANA 时区与夏令时
- 转换历史记录
- macOS 实现（接口预留）

> 「模拟 Ctrl+C 兜底」原在此列表；2026-11-26 用户决议推翻 2026-11-25 的否决，改为**可选回退**实现（见 §9 与设置「划词读取增强」，默认开）。

## 9. 划词兼容性

划词读取优先使用 Windows UIA 或 Linux X11 PRIMARY。Windows 读取失败时，可通过「划词读取增强」（默认开）启用复制回退。Navicat 的文本编辑器 `TEEAutoCompleteMemo` 和表格单元格编辑器 `TNavicatInplaceEdit` 使用 Windows 复制消息。其他符合回退条件的控件使用 Ctrl+C。

无障碍读取能否成功，由目标应用是否向系统辅助功能暴露选区决定：

| 应用 | 无障碍路径 | 回退后 |
|---|---|---|
| Chrome / Edge / Firefox、Office | 直接选中即可读取 | 不触发回退 |
| VS Code 编辑器 | ✅ 实测可读（若读不到，需开屏幕阅读器优化模式 `Shift+Alt+F1`） | **回退不触发**（VS Code 家族在内嵌终端黑名单：读不到时焦点几乎必然在集成终端，Ctrl+C 会中断命令） |
| Windows Terminal / CMD | 终端自己持有选区时可读 | **回退不触发**（终端进程黑名单） |
| 终端内的 TUI（opencode、vim 等） | 需按住 `Shift` 让终端接管选择 | 同上，终端不回退 |
| 钉钉（自绘聊天气泡等） | ❌ 不向 UIA 暴露选区 | ✅ 回退读取（本功能的直接动因） |
| WinUI 记事本 | ❌ 退化空 range | ✅ 回退可取 |
| 管理员权限窗口 | ❌ UIPI 双向拦截 | ❌ 同样不回退（按键发不进去） |

复制回退的行为约束：

- 仅在无障碍读取失败、设置开启、前台非终端且非提权窗口时触发
- 触发前备份剪贴板全部格式，读取后立即还原；备份超 32MB 或剪贴板被占用则放弃回退
- 复制没有发生（350ms 内剪贴板序列号未变）时按未选中处理，不会把旧剪贴板内容误当选区；慢应用的迟到写入由后台复查兜底还原
- 临时复制与还原不会进入 Quick 的剪贴板历史（复用粘贴抑制机制）
- 残余副作用：还原个别失败时剪贴板残留临时内容；GDI 句柄类格式（CF_BITMAP）备份跳过，还原后依赖 CF_DIB 保图片粘贴；无选区时部分编辑器按整行复制，可能把整行当预填
- **隐私提示**：系统 Win+V 剪贴板历史、云同步、第三方剪贴板管理器可能记录回退瞬间的选中文本（还原只恢复本机剪贴板当前值）；敏感内容场景建议关闭该开关

- 读取失败不阻断浮层打开：转换显示空输入框，启动器保留上次查询词。
- 读取期间忽略重复按下的 Quick 全局热键，结果返回后可再次触发。
- 不做自动开启应用无障碍模式、不自动改 opencode 鼠标配置，均由用户自行选择。
- 兼容性说明与开关同步展示在 **设置 → 常规页底部「划词读取说明」**。
