# 全局约定

## 热键

| 动作           | 默认        | 可改 |
|----------------|-------------|------|
| 打开启动器     | `Alt+Space` | 是   |
| 打开剪贴板历史 | `Alt+V`     | 是   |
| 打开转换       | `Alt+Q`     | 是   |

- 注册失败不静默：系统通知 + 设置页红色标记，并给出备选；多个组合失败时汇总为一条通知
- 同一时刻只有一个浮层可见；按另一个热键会切换模式
- 浮层打开时再次按同一热键 → 关闭（切换语义）
- 从外部应用打开启动器或转换时，先读取选区再显示。读取期间或关闭并恢复焦点期间的重复热键会忽略。

## 浮层行为

- 显示位置：鼠标所在显示器工作区，水平居中，垂直距顶 20%
- 尺寸：所有主浮层宽 640px；启动器 / 转换浮层一屏约 8 行（窗口高 480px，行高 48px），超出滚动；剪贴板浮层按内容动态调高（120–560px），不适用固定一屏行数。JSON 详情为独立窗口，不跟随主浮层宽度
- 窄屏时剪贴板预览收窄以保留列表宽度；主浮层不足 480px 时只显示列表，筛选项可横向滚动
- 失焦隐藏；`Esc` 隐藏；隐藏后焦点回到触发前的窗口
- 不进入任务栏，不出现在 `Alt+Tab`
- 显示时保留上一次的模式与查询词（启动器保留，剪贴板清空搜索词）

## 错误提示

- 所有失败落到浮层内提示或系统 toast，文案说明下一步能做什么
- 禁止出现 `HRESULT`、`0x8007...`、堆栈给最终用户

## 键盘操作

| 场景 | 按键 | 行为 |
|---|---|---|
| 全局 | `Esc` | 关闭浮层 |
| 启动器 | `↑` `↓` | 移动选中 |
| 启动器 | `Enter` | 执行（应用=打开 / 翻译=复制 / 在线=打开浏览器） |
| 启动器 | `Ctrl+Enter` | 同上但不关闭 |
| 剪贴板 | `↑` `↓` / `PgUp` `PgDn` | 移动 |
| 剪贴板 | `Enter` | 粘贴 |
| 剪贴板 | `Ctrl+Enter` | 仅复制 |
| 剪贴板 | `Ctrl+P` | 置顶切换 |
| 剪贴板 | `Delete` / `Shift+Delete` | 删除 / 永久删除 |
| 剪贴板 | `Tab` / `Shift+Tab` | 切换类型过滤 |

规则：
- 焦点永远在输入框，方向键由列表拦截
- 鼠标悬停不改变选中项，点击才选中
- 输入法组合期间不响应方向键与回车
