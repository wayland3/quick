# 剪贴板历史

## 记录类型

| 类型     | 来源格式            | 存储                        |
|----------|---------------------|-----------------------------|
| 文本     | `CF_UNICODETEXT`    | `text` + `preview`          |
| 富文本   | `CF_HTML`、`CF_RTF` | 原始格式 + 纯文本预览       |
| 图片     | `CF_DIB` / PNG      | `blobs/` 原图 + 缩略图      |
| 文件列表 | `CF_HDROP`          | JSON 数组（路径、是否存在） |

不记录：空内容、纯空白、仅格式无内容。

## 入库规则

- 去重键：`sha256(kind + 规范化内容)`。重复内容**不新增条目**，只增加计数并刷新最后使用时间
- 文本预览保留前 512 字符，去除控制字符；全文上限 256KB，超出截断并标记「已截断」
- 图片上限 8MB，超出只保留缩略图并标记「原图过大」

## 面板交互

- 打开搜索框自动聚焦
- 输入关键词即时过滤，`Tab` 切换类型筛选
- 选中条目右侧显示预览，不写入系统剪贴板

## 激活（粘贴）流程

1. 隐藏浮层，恢复目标窗口焦点
2. 将条目写入系统剪贴板
3. 发送 `Ctrl+V` 粘贴, 不同系统可能不一样，也可能是 `ctrl+shift+v`
4. 条目保留在剪贴板，便于手动再粘

失败时只写入剪贴板并提示用户手动粘贴。

可选设置「粘贴后还原原剪贴板」（默认关闭）：开启后 300ms 后还原步骤 1 之前的剪贴板快照。

## 保留与容量

| 规则        | 默认值                       | 可改                    |
|-------------|------------------------------|-------------------------|
| TTL         | 15 天（按 `last_copied_at`） | 7 / 15 / 30 / 90 / 永不 |
| 置顶项      | 豁免 TTL 与自动淘汰          | —                       |
| 条数上限    | 10,000                       | 1,000–50,000            |
| 单条文本    | 256KB                        | 否                      |
| 单张图片    | 8MB                          | 否                      |
| blob 总预算 | 500MB                        | 100MB–2GB               |
| 清理时机    | 启动 + 每 6h + 每 200 次写入 | 否                      |

超预算时按「最久未使用且未置顶」淘汰；置顶项永不自动删除。
