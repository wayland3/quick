# Quick 上线前手动测试清单

> 本文档用于 v1.0 上线前的全面手动验证。建议在真机环境完成所有 P0 项，P1/P2 根据时间选择执行。

---

## 测试环境要求

- **操作系统**：Windows 10/11（64位）
- **分辨率**：至少测试 1080p 和 2K/4K 缩放场景
- **多显示器**：至少双屏环境（含不同缩放比例）
- **权限**：标准用户 + 管理员用户各测试一轮

---

## P0 核心功能（必须全部通过）

### 1. 应用启动与托盘

- [ ] 双击 exe 正常启动，无报错
- [ ] 系统托盘图标显示
- [ ] 右键托盘菜单：设置、退出
- [ ] 再次运行 exe，不会启动第二个实例（单实例检查）
- [ ] 开机自启功能（设置中开启后重启验证）

### 2. 热键系统

- [ ] `Alt+Space` 打开启动器
- [ ] `Alt+V` 打开剪贴板历史
- [ ] 浮层打开时再按同一热键 → 关闭
- [ ] 浮层打开时按另一个热键 → 切换模式
- [ ] 设置页修改热键绑定，新键立即生效
- [ ] 热键被占用时（如 PowerToys Run），启动时给出明确提示（托盘气泡 + 设置页红色标记）
- [ ] `Esc` 关闭浮层

### 3. 浮层窗口行为

- [ ] 浮层显示在鼠标所在显示器，水平居中，垂直距顶 20%
- [ ] 失焦自动隐藏（点击其他窗口）
- [ ] 不进入任务栏
- [ ] 不出现在 `Alt+Tab` 切换列表
- [ ] 隐藏后焦点回到触发前的窗口
- [ ] 双屏不同缩放比例下位置正确（100%/150%/200%）

### 4. 启动器功能

- [ ] 输入应用名（如 `chr`），首条匹配 Chrome
- [ ] 输入 `not`，首条匹配记事本
- [ ] 方向键 `↑↓` 移动选中项
- [ ] `Enter` 启动应用
- [ ] 失效快捷方式（如已卸载应用）给出中文提示
- [ ] 输入 `> lock` 执行锁屏命令
- [ ] 输入 `> settings` 打开设置
- [ ] 输入 `> clear` 清空剪贴板
- [ ] 输入 `> rebuild` 重建应用索引
- [ ] 输入 `> quit` 退出应用

### 5. 剪贴板历史 - 基础功能

- [ ] 复制文本，`Alt+V` 能看到新条目
- [ ] 复制图片，能看到缩略图
- [ ] 复制文件（资源管理器 `Ctrl+C`），能看到文件列表
- [ ] 搜索框输入中文 1 个字能即时过滤
- [ ] `Tab` 切换类型过滤（全部/文本/图片/文件/收藏）
- [ ] 方向键 `↑↓` 移动选中项
- [ ] `Enter` 粘贴选中项到目标窗口
- [ ] `Ctrl+Enter` 仅复制不粘贴
- [ ] `Ctrl+P` 置顶/取消置顶
- [ ] `Delete` 删除条目
- [ ] `Shift+Delete` 永久删除

### 6. 剪贴板历史 - 粘贴流程

- [ ] 从历史粘贴文本（中文、英文、emoji）到记事本
- [ ] 从历史粘贴到 Chrome 地址栏
- [ ] 从历史粘贴到 VS Code
- [ ] 连续粘贴 5 次，内容正确无丢失
- [ ] 粘贴后条目仍保留在系统剪贴板（可手动再粘）
- [ ] **管理员权限窗口**：给出提示「已复制，请手动粘贴」
- [ ] 可选设置「粘贴后还原原剪贴板」：开启后 300ms 还原

### 7. 剪贴板历史 - 数据管理

- [ ] 复制同一条内容 3 次，只有 1 条记录，计数显示为 3
- [ ] 置顶项不自动删除（即使超过 TTL）
- [ ] 超过 TTL 的条目自动清理（默认 15 天）
- [ ] 超过条数上限（10,000）时按 LRU 淘汰
- [ ] 超过 blob 预算（500MB）时按 LRU 淘汰图片

### 8. 设置窗口

- [ ] `Ctrl+,` 打开设置
- [ ] 修改热键绑定，立即生效
- [ ] 修改主题（浅色/深色/跟随系统），立即切换
- [ ] 修改剪贴板保留策略（TTL、条数、预算），立即生效
- [ ] 开机自启开关有效
- [ ] 数据路径显示正确
- [ ] 关闭设置窗口，焦点回到主窗口

## P1 重要边界情况（建议全部通过）

### 9. 输入法与组合键

- [ ] 输入法开启状态下，方向键不响应（避免误操作）
- [ ] 输入法组合期间（如拼音输入中），`Enter` 不触发启动
- [ ] `Ctrl+Shift` 切换输入法后，热键仍正常

### 10. 多显示器与缩放

- [ ] 主屏 100%、副屏 150%，浮层位置正确
- [ ] 主屏 200%、副屏 100%，浮层位置正确
- [ ] 拖动应用到不同屏幕，浮层跟随鼠标
- [ ] 笔记本外接显示器，合盖后浮层位置正确

### 11. 特殊窗口场景

- [ ] 最小化窗口呼出后恢复焦点
- [ ] 全屏应用（如视频播放器）切到桌面后呼出
- [ ] 远程桌面窗口（如 RDP）不响应 `Ctrl+V`，给出提示
- [ ] 虚拟机窗口不响应合成按键，给出提示

### 12. 剪贴板特殊内容

- [ ] 复制超大文本（>256KB），标记「已截断」
- [ ] 复制超大图片（>8MB），只保留缩略图并标记「原图过大」
- [ ] 复制 HTML 格式（如网页内容），保留格式粘贴
- [ ] 复制 RTF 格式（如 Word 内容），保留格式粘贴
- [ ] 复制空内容、纯空白，不入库
- [ ] 复制仅格式无内容，不入库

### 13. 应用索引

- [ ] 新安装应用后，索引自动刷新（或手动 `> rebuild`）
- [ ] 卸载应用后，索引中不再显示
- [ ] 失效快捷方式（目标不存在）给出提示
- [ ] 环境变量路径（如 `%SystemRoot%\...`）正确解析

### 14. 错误处理

- [ ] 所有错误提示为中文，无 `HRESULT`、`0x8007...` 等技术细节
- [ ] 数据库损坏时，给出明确提示并备份旧数据
- [ ] 热键注册失败时，给出备选方案提示
- [ ] 焦点恢复失败时，降级为「已复制，请手动粘贴」

## 回归测试场景（完整流程）

按顺序完成以下操作，验证端到端流程：

1. **启动应用**
   - 双击 exe，托盘图标出现
   - 检查日志无报错

2. **剪贴板历史完整流程**
   - 复制 20 条不同内容（文本、图片、文件）
   - `Alt+V` 打开历史
   - 搜索「测试」，验证过滤
   - `Tab` 切换到「图片」过滤
   - 选中一条，`Ctrl+P` 置顶
   - `Delete` 删除一条
   - 选中一条，`Enter` 粘贴到记事本
   - 验证粘贴内容正确

3. **启动器完整流程**
   - `Alt+Space` 打开启动器
   - 输入 `chr`，选中 Chrome
   - `Enter` 启动
   - 输入 `> lock`，锁屏
   - 解锁后验证应用仍在运行

4. **设置修改**
   - `Ctrl+,` 打开设置
   - 修改启动器热键为 `Alt+Q`
   - 验证新热键生效，旧热键失效
   - 修改主题为「深色」
   - 验证界面立即切换

5. **重启验证**
   - 关闭应用
   - 重新打开
   - 验证剪贴板历史数据完整
   - 验证设置保留
