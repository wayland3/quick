# 发布测试清单

> v1.0 上线前手动验证。P0 必须全部通过，P1/P2 根据时间选择执行。

## 测试环境

- Windows 10/11（64位）
- 至少 1080p，测试 2K/4K 缩放
- 双屏环境（含不同缩放比例）
- 标准用户 + 管理员用户各一轮

## P0 核心功能

### 1. 启动与托盘

- [ ] exe 启动无报错
- [ ] 托盘图标显示
- [ ] 右键菜单：设置、退出
- [ ] 单实例检查
- [ ] 开机自启有效

### 2. 热键

- [ ] `Alt+Space` 打开启动器
- [ ] `Alt+V` 打开剪贴板历史
- [ ] 同键再按关闭浮层
- [ ] 不同热键切换模式
- [ ] 热键改绑立即生效
- [ ] 热键冲突有提示
- [ ] `Esc` 关闭浮层

### 3. 浮层窗口

- [ ] 显示在鼠标所在显示器，水平居中，垂直距顶 20%
- [ ] 失焦自动隐藏
- [ ] 不进任务栏、不出现在 Alt+Tab
- [ ] 隐藏后焦点回到原窗口
- [ ] 多缩放比例下位置正确

### 4. 启动器

- [ ] 输入应用名匹配
- [ ] 应用图标显示
- [ ] 方向键导航、Enter 启动
- [ ] 内置命令：`> lock` / `> settings` / `> clear` / `> rebuild` / `> quit`
- [ ] 划词预填（Chrome/Edge/VS Code/Terminal）

### 5. 剪贴板历史

- [ ] 复制文本/图片/文件可见
- [ ] 搜索过滤
- [ ] `Tab` 切换类型
- [ ] 方向键导航、Enter 粘贴
- [ ] `Ctrl+P` 置顶、`Delete` 删除
- [ ] 粘贴到记事本/Chrome/VS Code
- [ ] 管理员窗口提示手动粘贴
- [ ] 去重、TTL 清理、置顶豁免

### 6. 设置

- [ ] `Ctrl+,` 打开设置
- [ ] 热键/主题/保留策略修改立即生效
- [ ] 开机自启开关有效

## P1 边界情况

### 7. 输入法与多屏

- [ ] 输入法开启时方向键不响应
- [ ] 多屏不同缩放比例浮层位置正确

### 8. 特殊窗口

- [ ] 最小化窗口恢复焦点
- [ ] 全屏应用切到桌面后呼出
- [ ] 远程桌面/虚拟机提示

### 9. 剪贴板特殊内容

- [ ] 超大文本标记截断
- [ ] 超大图片不保存原图
- [ ] 截图粘贴方向正确
- [ ] HTML/RTF 保留格式
- [ ] 空内容/纯格式不入库

### 10. 错误处理

- [ ] 错误提示为中文
- [ ] 数据库损坏有提示
- [ ] 热键冲突有备选提示

## P2 性能

- [ ] 冷启动 < 3s
- [ ] 热键打开延迟 < 200ms
- [ ] 搜索响应 < 100ms（1000 条）
- [ ] 粘贴延迟 < 300ms
- [ ] 10000 条历史搜索流畅
- [ ] 连续复制无内存泄漏

## P3 已知限制

- [ ] 管理员窗口提示「目标窗口权限较高」
- [ ] 热键冲突提示换绑
- [ ] HTML/RTF 跨应用格式可能丢失
