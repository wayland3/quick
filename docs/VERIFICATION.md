# 改动后验证清单

AI 改完代码后，按此清单验证。

## 第一步：自动验证（必做）

```powershell
# 1. 编译检查
cd E:\quick\src-tauri
cargo check

# 2. 运行所有单元测试
cd E:\quick
npm.cmd run verify
```

**通过标准**：
- [ ] 编译无错误
- [ ] 所有单元测试通过（Rust 139 个 + 前端 104 个）
- [ ] 无新增 lint 警告

## 第二步：手动验证（按改动范围选择）

### 如果改了 `platform/clipboard.rs`

- [ ] 复制文本，Alt+V 能看到
- [ ] 复制图片，Alt+V 能看到缩略图
- [ ] 复制文件，Alt+V 能看到文件列表
- [ ] 从历史粘贴，内容正确

### 如果改了 `platform/focus.rs`

- [ ] Alt+Space 呼出，Esc 关闭，焦点回到原窗口
- [ ] 在记事本、Chrome、VS Code 分别测试
- [ ] 最小化窗口呼出后恢复

### 如果改了 `platform/input.rs`

- [ ] 从历史粘贴文本（中文、英文、emoji）
- [ ] 从历史粘贴到记事本、Chrome、VS Code
- [ ] 连续粘贴 5 次，无丢失

### 如果改了 `platform/apps.rs`

- [ ] Alt+Space 输入 `chr`，首条是 Chrome
- [ ] 按 Enter，Chrome 启动
- [ ] 输入 `not`，首条是记事本

### 如果改了 `services/hotkey.rs`

- [ ] 启动时热键注册成功
- [ ] 设置页改绑热键，新键生效、旧键失效

### 如果改了 `services/storage.rs`

### 如果改了 `services/paste.rs`

- [ ] 管理员窗口下给出提示

### 如果改了 `services/window.rs`

- [ ] 浮层显示位置正确（鼠标所在显示器）

### 如果改了 `commands/` 层

## 第三步：回归测试（可选）

如果改动较大，跑一遍完整流程：

1. 启动应用
2. 复制 20 条不同内容（文本、图片、文件）
3. Alt+V 打开历史，搜索、筛选、置顶、删除
4. 从历史粘贴到记事本
5. Alt+Space 打开启动器，搜索并打开应用
6. 设置页改绑热键
7. 关闭应用，重启，数据完整

## 常见问题

### 编译失败

```
error: cannot find type `XXX` in this scope
```

检查：
- 是否漏了 `use` 语句
- 是否改了模块结构但没更新引用

### 单元测试失败

```
test XXX ... FAILED
```

检查：
- 是否改了数据结构但没更新测试
- 是否改了业务逻辑但测试还是旧预期

### 手动验证失败

- 热键不响应：检查是否被其他程序占用
- 剪贴板不捕获：检查监听线程是否启动
- 焦点不恢复：检查 `AttachThreadInput` 是否成对
