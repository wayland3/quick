# JSON 详情失焦开关修复 mini-design

- 改动：`JsonDetailPanel` 移除主浮层事件/单窗口失焦隐藏；`ConvertPanel` 卸载不发隐藏命令；`lib.rs` 与 `window.rs` 统一处理失焦。
- 契约：失焦（主浮层显示或已隐藏）按 `json_detail_close_on_blur` 决定是否隐藏详情；主动关闭、模式或结果切换总是隐藏；设置读取失败沿用默认隐藏。
- 风险：详情显示后焦点交回主面板，必须等待双窗口焦点稳定且前台在应用外才触发；显示与主动隐藏需串行，避免迟到的显示重新弹窗。不新增依赖、IPC 或平台接口。
- 验证：前端事件/卸载回归测试，Rust 隐藏原因单测，完整 `verify`；窗口点击外部场景需真机验收。
