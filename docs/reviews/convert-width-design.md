# 主浮层宽度与 JSON 详情字号

## 契约
- `OverlayManager::show`、`show_webview` 和 `compute_overlay_resize` 的主浮层宽度均为 640 逻辑像素；启动器、剪贴板、转换共用，不改变各模式高度规则。
- 初始隐藏窗口与 `.qw-panel` 最大宽度也为 640px，避免首次显示或 CSS 约束与窗口尺寸不一致；设置窗口不受影响。
- JSON 详情仍是独立窗口，只将树正文从 12px 改为 11px；详情按更紧凑的行高估算高度，短内容居中、长内容顶对齐的规则不变。
- 工作区变窄时剪贴板预览宽度随主浮层收缩，低于 480px 时只保留结果列表；搜索栏筛选项在窄屏可横向滚动。

## 验证
- 单测锁定普通及动态高度的主浮层宽度，覆盖居中主浮层与详情并排布局和窄屏回退。
- 全量 `npm.cmd run verify`；真机确认三种模式宽度一致及详情长内容滚动。

## 设计复核
- 独立复核提出两点：窄屏剪贴板布局须闭环、正文缩小后须同步高度估算。已将预览/筛选响应式规则纳入契约，高度改按 21px/行估算。

## 实现复核
- 独立复核结论：PASS。三种主模式的显示、尺寸调整、初始窗口和 CSS 均使用 640px；JSON 正文为 11px，设置窗口不受影响。
- 待真机确认：三个热键打开后的宽度一致，长 JSON 详情可滚动。
