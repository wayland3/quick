## 设计与验证

- `compute_detail_layout` 保持现有宽度和高度计算；纵向从主浮层顶部起始，底部越界才上移，超出整个工作区时贴顶并保留滚动。
- 测试覆盖顶部对齐、底部溢出、顶部越界、多屏工作区偏移和高 DPI。
- `npm.cmd run verify` 全绿：前端 128 项、Rust 272 项通过，4 项既有真机测试跳过。

## 评审遗留

- 非整数 DPI 且工作区顶部不落在缩放整数倍时，逻辑坐标转 `i32` 再回物理坐标可能有约 1 像素的贴边偏差；不影响当前布局规则，真机验收时一并观察。
- 实际窗口位置仍需真机确认。
