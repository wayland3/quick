## NONBLOCK（已全部修复）

1. **产品文档表述矛盾**（docs/product/features/clipboard.md:18）：「>8MB 超出只保留缩略图」→ 改为「不保存原图，只留标记条目（无缩略图）」。
2. **回写竞态孤儿**（services/thumbnail.rs）：`set_thumb_path` 改为返回 affected rows；命中 0 行（条目已被删除）时删除刚写的缩略图文件并跳过 emit。
3. **Drop 排空代价未标注**：Drop 注释标明最坏 8 次全尺寸解码、换取退出前已投递任务全部落盘。
4. **blob 预算口径不对称**（services/storage.rs `blob_usage_on_disk`）：注释说明占用侧含 thumbs 而估算侧只减 byte_size，方向保守（最多多淘汰一条），不值得为每条维护 thumb 实际大小。
5. **缩略图加载失败回退**（src/components/ItemRow.tsx）：`onError` 置状态回退类型图标（覆盖删除与 thumb-ready 竞态、文件缺失）。

## 实现备注

- 缩略图文件名沿用原图内容 hash，与原图一一对应，无额外映射。
- 工作线程自开数据库连接（WAL + busy_timeout），与监听线程互不阻塞。
- `image::DynamicImage::thumbnail` 是「适配边界」语义会放大小图，生成前先判尺寸。
