# JSON 详情关闭按钮回归修复

**评审级别**：L2（前端按钮、IPC、后端窗口状态）
**日期**：2026-11-26
**结论**：第 1 轮 FAIL；修复后第 2 轮 PASS

## 设计

- 关闭按钮调用 `json_detail_hide(dismiss=true)`；结果切换调用 `dismiss=false`。
- 隐藏操作共用可见性锁；隐藏成功后清空内容并标记手动关闭，拒绝迟到展示，切换非 JSON 结果后清除标记。
- 主动隐藏失败返回错误供按钮提示重试，不新增窗口 API 权限。

## 评审

- 第 1 轮 BLOCKER：后端吞掉 `window.hide()` 错误；可见性锁不能阻止关闭后才执行的展示请求。
- 修复：手动关闭走返回 `Result` 的路径；锁内维护 `dismissed` 状态，展示前检查并在普通结果切换后重置。
- 第 2 轮只复核上述两项，结论 PASS。
