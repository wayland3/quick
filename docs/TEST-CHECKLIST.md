# 手动测试清单

每个涉及 `platform/` 的任务都要跑，并在任务备注里记录环境（Windows 版本 / 缩放 / 是否多屏）。

## 基础

- [ ] 记事本、VS Code、Chrome 地址栏、Word、微信：`Alt+V` 回车粘贴正确
- [ ] 管理员运行的记事本：提示「权限较高」，剪贴板可用
- [ ] 输入法（微软拼音）开启时粘贴
- [ ] 选中 emoji + 中文 + 多行文本

## 焦点

- [ ] 触发前窗口是最小化状态，关闭浮层后恢复
- [ ] 触发前窗口在另一个显示器，关闭后焦点回去
- [ ] 连续开关 20 次，焦点每次都正确

## 剪贴板

- [ ] 复制 1MB 文本（截断标记）
- [ ] 复制 10MB 图片（仅缩略图）
- [ ] 资源管理器复制 3 个文件
- [ ] Excel 复制单元格（OpenClipboard 占用场景）
- [ ] 复制后立刻按 `Alt+V`（30ms 延迟是否足够）

## 显示

- [ ] 100% / 150% / 200% 缩放下浮层清晰且位置正确
- [ ] 竖屏 + 双屏
- [ ] 全屏视频、全屏浏览器（F11）
- [ ] 任务栏在顶部/左侧时定位正确

## 生命周期

- [ ] 二次启动不产生新实例
- [ ] 退出后热键全部释放（再按无反应）
- [ ] 强制结束进程后重启，数据完整、无锁库
