# Quick 功能规格

## 1. 全局约定

### 1.1 热键

| 动作           | 默认        | 可改 |
|----------------|-------------|------|
| 打开启动器     | `Alt+Space` | 是   |
| 打开剪贴板历史 | `Alt+V`     | 是   |

- 注册失败不静默：托盘气泡 + 设置页红色标记，并给出备选
- 同一时刻只有一个浮层可见；按另一个热键会切换模式
- 浮层打开时再次按同一热键 → 关闭（切换语义）

### 1.2 浮层行为

- 显示位置：鼠标所在显示器工作区，水平居中，垂直距顶 20%
- 失焦隐藏；`Esc` 隐藏；隐藏后焦点回到触发前的窗口
- 不进入任务栏，不出现在 `Alt+Tab`
- 显示时保留上一次的模式与查询词（启动器保留，剪贴板清空搜索词）

### 1.3 错误提示

- 所有失败落到浮层内提示或系统 toast，文案说明下一步能做什么
- 禁止出现 `HRESULT`、`0x8007...`、堆栈给最终用户

### 1.4 键盘操作

| 场景 | 按键 | 行为 |
|---|---|---|
| 全局 | `Esc` | 关闭浮层 |
| 通用 | `Ctrl+,` | 打开设置 |
| 启动器 | `↑` `↓` | 移动选中 |
| 启动器 | `Enter` | 打开 |
| 剪贴板 | `↑` `↓` / `PgUp` `PgDn` | 移动 |
| 剪贴板 | `Enter` | 粘贴 |
| 剪贴板 | `Ctrl+Enter` | 仅复制 |
| 剪贴板 | `Ctrl+P` | 置顶切换 |
| 剪贴板 | `Delete` / `Shift+Delete` | 删除 / 永久删除 |
| 剪贴板 | `Tab` / `Shift+Tab` | 切换类型过滤 |

规则：
- 焦点永远在输入框，方向键由列表拦截
- 鼠标悬停不改变选中项，点击才选中
- 输入法组合期间不响应方向键与回车

## 2. 启动器

### 2.1 输入解析

| 输入 | 行为 |
|---|---|
| 纯文本 | 应用搜索 |
| `> <命令>` | 内置命令（锁屏、睡眠、设置、清空剪贴板、重建索引、退出） |

### 2.2 结果与排序

- 最多 12 条，分组：应用 / 命令
- 匹配优先级：完全前缀 > 词首缩写（`vsc` → Visual Studio Code）> 子串 > 模糊
- 同分时按 frecency：`score = 匹配分 × (1 + ln(1+使用次数)) × 时间衰减`，衰减半衰期 14 天

### 2.3 执行

- `Enter` 打开应用
- 执行失败时保留面板并提示原因（应用已卸载 / 无权限 / 找不到关联程序）

## 3. 剪贴板历史

### 3.1 记录类型

| 类型 | 来源格式 | 存储 |
|---|---|---|
| 文本 | `CF_UNICODETEXT` | `text` + `preview` |
| 富文本 | `CF_HTML`、`CF_RTF` | 原始格式 + 纯文本预览 |
| 图片 | `CF_DIB` / PNG | `blobs/` 原图 + 缩略图 |
| 文件列表 | `CF_HDROP` | JSON 数组（路径、是否存在） |

不记录：空内容、纯空白、仅格式无内容。

### 3.2 入库规则

- 去重键：`sha256(kind + 规范化内容)`。重复内容**不新增条目**，只增加计数并刷新最后使用时间
- 文本预览保留前 512 字符，去除控制字符；全文上限 256KB，超出截断并标记「已截断」
- 图片上限 8MB，超出只保留缩略图并标记「原图过大」
- 来源应用：进程名、窗口标题（**不参与搜索、不写日志**）
- 入库延迟 ≤ 300ms

### 3.3 面板交互

- `Alt+V` 打开，聚焦搜索框，默认显示最近 50 条
- 搜索：中文 1 字起即时过滤（1–2 字回退 `LIKE`，≥3 字走 FTS）；防抖 80ms
- 筛选：`Tab` 循环 全部 / 文本 / 图片 / 文件 / 收藏
- 列表项显示：类型图标、首行摘要、来源应用、相对时间、置顶标记、尺寸标记
- 右侧预览：文本全文滚动、图片等比、文件列表带存在状态
- 选中即预览，不写入剪贴板

### 3.4 激活（粘贴）流程

1. 记录当前前台窗口 → 隐藏浮层
2. 恢复前台窗口焦点（≤150ms，失败则提示）
3. 将条目以原始格式写入系统剪贴板
4. 抑制监听 1.5 秒（按内容 hash），**不新增历史、不调整顺序**
5. 发送 `Ctrl+V`
6. 条目**保留在系统剪贴板**（便于手动再粘）

失败降级：
- 焦点恢复失败或目标提权 → 只写剪贴板 + toast「已复制，请手动粘贴」

可选设置「粘贴后还原原剪贴板」（默认关闭）：开启后 300ms 后还原步骤 1 之前的剪贴板快照。

### 3.5 保留与容量

| 规则 | 默认值 | 可改 |
|---|---|---|
| TTL | 15 天（按 `last_copied_at`） | 7 / 15 / 30 / 90 / 永不 |
| 置顶项 | 豁免 TTL 与自动淘汰 | — |
| 条数上限 | 10,000 | 1,000–50,000 |
| 单条文本 | 256KB | 否 |
| 单张图片 | 8MB | 否 |
| blob 总预算 | 500MB | 100MB–2GB |
| 清理时机 | 启动 + 每 6h + 每 200 次写入 | 否 |

超预算时按「最久未使用且未置顶」淘汰；置顶项永不自动删除。

### 3.6 隐私

- 数据仅本地明文存储；设置页明确写出这一点
- 日志与崩溃信息不含剪贴板内容、窗口标题、文件路径

## 4. 设置项

| 分组 | 项 | 默认 |
|---|---|---|
| 常规 | 开机自启 | 关 |
| 常规 | 主题 | 跟随系统 |
| 热键 | 启动器 / 剪贴板 | `Alt+Space` / `Alt+V` |
| 剪贴板 | 启用记录 | 开 |
| 剪贴板 | 记录图片 / 文件列表 | 开 / 开 |
| 剪贴板 | TTL | 15 天 |
| 剪贴板 | 条数上限 | 10,000 |
| 剪贴板 | blob 预算 | 500MB |
| 剪贴板 | 粘贴后还原原剪贴板 | 关 |

## 5. 边界与限制

1. 管理员权限窗口不支持自动粘贴，只能复制后手动粘贴
2. 部分全屏独占游戏会遮住浮层；切到无边框窗口模式可正常使用
3. 极少数应用不响应合成 `Ctrl+V`（如某些远程桌面/虚拟机窗口），需手动粘贴
4. `Alt+Space` 可能与 PowerToys Run、输入法等冲突，需换绑
